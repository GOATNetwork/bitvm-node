# TLA+ spec table, run by check.sh (`make tla`, CI job `tla-plus`).
# One row per TLC run:  tier | config | spec | description
# Only the current code is checked - no row models old, pre-fix code.
#   pass       - models the current code; must verify (a fixed bug's regression check)
#   live       - models the current code with a known unfixed bug; fails the run until fixed,
#                then model the fix in the config and make it pass
#   design     - proposed fix for a live bug, not in the code yet; must verify
#   boundary   - sweep outside a fix design's ParamsOK; must find a counterexample (the condition is necessary)
# See check.sh for how each tier is judged and README.md "Formal verification (TLA+)".
